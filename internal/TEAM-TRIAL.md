# 组内试用说明

搭了一个 RTL / GEM5 性能对比页面，大家可以先试用一下：

http://172.19.20.37:8002/?analysis=1

组内网络可直接打开，不需要 SSH 转发。

1. 左侧选择 baseline，也可以在 Baseline A 里填 CI 链接或 Run ID。
2. B 填要对比的 CI 链接或 Run ID，点击“详细分析”。有多个归档配置时，选好配置再点一次。
3. 结果出来后，可以搜索计数器、选择分类，再按 benchmark 或 SimPoint 查看。默认按绝对差值 `|B − A|` 降序，也能切到百分比排序。
4. 想看某个切片的原始计数器，选 SimPoint 和具体切片，再搜索 raw 计数器；这时不加权。

首次分析需要读取归档，等一会儿，已有缓存会快一些。不用了可以点“停止分析”，关闭网页不会取消后台任务。
目前先看 SPEC 单线程数据；RTL 的 Intel Topdown 还有缺项，暂时先忽略。遇到问题把 CI 链接、操作步骤和报错发我就行。
